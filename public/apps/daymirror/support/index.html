How can we help?

For Daymirror support, email support@hiorio.com.

Please include your device model, OS version, Daymirror version, and the steps that led to the issue. Remove personal schedule details from screenshots. Never send your Apple Account password.

Plan a day, then record what happened

Each cell represents ten minutes; one row contains one hour. You can switch to ten-minute rows in Settings. Use the add button to create a plan or actual entry. Swipe over the schedule to scroll, and hold a block before moving it. An elapsed plan can be copied to Actual; future time is not recorded as completed time.

Repeat plans and keep notes nearby

Fill recurring plans from a routine, or use Duplicate This Day to copy selected plans to other dates. Overwrite replaces plans in the chosen range; it keeps actual records. Keep to-dos and notes in the companion panel, and schedule a to-do as a plan when needed. Completing a to-do does not create actual time.

If iCloud changes are missing

  1. Check that the devices use the same Apple Account and iCloud is available for Daymirror.
  2. Open Daymirror on both devices while connected to the internet.
  3. In Settings, check pending uploads, the last server confirmation, and any conflict message. Use Sync Now. The to-do and note panel shows its own sync status.
  4. If a warning persists, record its wording and contact support. Keep the installed app and local data; do not clear them as a first troubleshooting step.

Offline changes wait for a connection. Background delivery can be delayed by the system. A different iCloud account or removed server history stops sync to protect existing records.

Which date is today?

Settings → Date & Time Zone lets you use the device's time zone or choose a fixed one. Today changes at midnight in that time zone. The day-start setting controls the timeline and reporting window. You can also choose the first day of the week. Changing display preferences does not rewrite saved instants.

Export your local data

Daymirror 1.0 (build 12) includes JSON export in Settings → data management. It saves a snapshot of the plans, actual entries, routines, activities, to-dos, notes, planner settings, locally stored revision history, and cached input drafts available on this device. Earlier text from deleted or edited items may be included.

The export does not fetch a complete copy from iCloud or include another device's unsynced changes. Save open edits and allow sync to finish first if you want recent changes included. Unsaved editor state that has not reached the draft cache is not included. The app does not provide JSON import or one-click restoration. Choose where to save the file and share it only with people you intend to give access.

Privacy and data requests

Read the Privacy Policy for storage and revision history. Follow the deletion instructions below to remove local and iCloud copies, or email support for guidance. Hiorio cannot directly read or remotely erase your private CloudKit database through developer administration.

Delete your Daymirror data

Daymirror stores data on each device you use and in your own iCloud account. Deleting an item inside the app may leave earlier revisions used for syncing. To remove all records and revision history, remove the app's local data from every device first, then delete its iCloud data. This order helps prevent an old installation from uploading retained data again.

1. Export anything you want to keep

Use the JSON export in the app's data management settings. The file includes data and earlier revisions stored on that device. Export separately from another device if it has changes that have not synced. Exported files remain wherever you save them and are not removed by the steps below.

2. Remove the app and its local data from every device

iPhone and iPad: Open Settings → General → iPhone Storage or iPad Storage → Daymirror → Delete App. Do not use Offload App; it keeps the app's data. Apple's device storage guide

Mac: Quit Daymirror using its menu or ⌘Q, then move Daymirror from Applications to the Trash. Deleting the application alone leaves its stored data. Remove its data folder as well:

  1. In Finder, choose Go → Go to Folder (⇧⌘G).
  2. Enter ~/Library/Containers/com.planudid.app.
  3. Confirm this is Daymirror's com.planudid.app folder, then move only that folder to the Trash. Do not delete the parent Containers or Library folders.
  4. In the Trash, select only the Daymirror app and data folder you just moved, and choose Delete Immediately. There is no need to delete other items in your Trash.

If you previously installed the separate Daymirror Mac app, quit and remove that app too. Check for its older ~/Library/Containers/com.planudid.mac folder and remove that folder in the same way if present. Do not delete other similarly named folders in bulk.

If the folder is absent or macOS blocks access, contact support instead of deleting a different folder. Repeat for other Mac user accounts where you used the app. Apple's Mac app removal guide

Include devices that are turned off or offline. Until you clear an old device, do not reopen its old Daymirror installation or reconnect it to iCloud. These steps do not remotely erase that device's local files.

3. Delete Daymirror's iCloud data

After clearing every device, use one device signed in to the Apple Account you used with Daymirror:

  • iPhone and iPad: Settings → your name → iCloud → Storage or Manage Account Storage → Daymirror. Choose its data deletion action and confirm. Button names such as Delete Data or Delete from iCloud vary by OS version. Apple's iCloud storage guide
  • Mac: System Settings → your name → iCloud → Manage → Daymirror → Delete from iCloud, then confirm. Apple's Mac iCloud deletion guide

Turning off the app's iCloud switch or deleting an exported JSON file does not erase its iCloud revision history. If Daymirror or its deletion action is missing, check which Apple Account you used and contact support. Do not delete another app's data or an entire device backup instead. Repeat iCloud deletion for each Apple Account if you used more than one with Daymirror.

4. Backups and reinstalling

Reinstall only after iCloud storage reflects the deletion and every old installation's local data has been removed. Earlier device backups, Time Machine or Finder backups, and saved app-data or JSON copies can still contain your records. Restoring them can bring old data back. If you also want those copies removed, manage them separately through the relevant backup or file service. Daymirror cannot erase those copies itself.

Need help? Email support@hiorio.com with your device, OS version, and the step you could not complete. Do not send your Apple Account password or a full schedule export. Support can guide you through deleting data under your control.

도움이 필요하신가요?

Daymirror 문의는 support@hiorio.com으로 보내 주세요.

기기 모델, OS와 앱 버전, 문제가 발생한 순서를 알려주세요. 화면 캡처에서는 개인 일정 내용을 가리고 Apple 계정 비밀번호는 보내지 마세요.

하루를 계획하고 실제를 남기기

한 칸이 10분이고 가로 여섯 칸이 한 시간입니다. 설정에서 10분 한 줄 방식으로 바꿀 수 있습니다. 추가 버튼으로 계획이나 실제 기록을 만들고, 일정 위를 쓸어 스크롤하거나 블록을 길게 누른 뒤 옮길 수 있습니다. 지나간 계획은 실제로 복사할 수 있으며 미래 시간을 이미 수행한 기록으로 남기지 않습니다.

계획 반복과 할 일·메모

루틴으로 반복 계획을 채우거나 ‘이날 일정 복제’에서 선택한 계획을 다른 날짜에 복사하세요. 덮어쓰기는 선택한 기간의 계획을 바꾸고 실제 기록은 유지합니다. 할 일과 메모를 패널에 모아 두고 필요할 때 할 일을 계획에 배치할 수 있습니다. 완료 체크는 실제 시간을 만들지 않습니다.

iCloud 변경이 보이지 않을 때

  1. 두 기기가 같은 Apple 계정을 사용하고 Daymirror에서 iCloud를 사용할 수 있는지 확인하세요.
  2. 인터넷에 연결한 상태에서 두 기기의 Daymirror를 열어주세요.
  3. 설정에서 전송 대기, 마지막 서버 확인 시각과 충돌 안내를 확인하고 ‘지금 동기화’를 누르세요. 할 일·메모 패널의 동기화 상태도 확인하세요.
  4. 안내가 계속되면 내용을 적어 지원으로 보내주세요. 문제 해결을 시작할 때 앱이나 로컬 데이터를 먼저 지우지 마세요.

오프라인 변경은 연결될 때까지 대기하며 백그라운드 반영은 시스템에 따라 늦어질 수 있습니다. 계정이 달라지거나 서버 이력이 삭제되면 기존 기록을 보호하기 위해 동기화가 멈춥니다.

오늘은 어떤 날짜인가요?

설정 → 날짜와 시간대에서 기기의 시간대를 자동 사용하거나 고정 시간대를 정할 수 있습니다. 오늘은 해당 시간대의 자정에 바뀝니다. 하루 시작 시각은 시간표와 집계 범위를 정하며 한 주의 시작 요일도 선택할 수 있습니다. 표시 설정을 바꿔도 저장한 실제 시각은 다시 쓰지 않습니다.

기기에 저장된 데이터 내보내기

Daymirror 1.0(빌드 12)부터 설정의 데이터 관리에서 JSON 파일을 내보낼 수 있습니다. 이 기기에 저장된 계획·실제·루틴·활동·할 일·메모·플래너 설정, 이전 변경 이력과 저장된 입력 초안을 담습니다. 삭제하거나 수정한 항목의 이전 내용도 포함될 수 있습니다.

iCloud 전체 데이터를 새로 조회하거나 다른 기기의 미동기화 내용까지 포함하는 기능은 아닙니다. 최근 변경을 담으려면 열린 편집 내용을 저장하고 동기화를 마친 뒤 내보내세요. 초안 저장소에 아직 반영되지 않은 편집 중 내용은 포함되지 않습니다. 현재 JSON 가져오기나 한 번에 복원하는 기능은 없습니다. 파일의 저장 위치를 직접 선택하고, 내용을 공개하려는 대상에게만 공유해 주세요.

개인정보와 데이터 문의

저장 방식과 변경 이력은 개인정보처리방침을 확인하세요. 로컬·iCloud 사본을 제거하려면 아래 삭제 절차를 따르거나 지원 이메일로 문의할 수 있습니다. Hiorio는 개발자 관리 도구로 사용자의 비공개 CloudKit 데이터베이스 내용을 직접 읽거나 원격 삭제할 수 없습니다.

Daymirror 데이터 삭제

Daymirror 데이터는 사용한 각 기기와 본인의 iCloud에 저장됩니다. 앱에서 일정을 삭제하면 동기화에 필요한 이전 변경 이력이 남을 수 있습니다. 모든 기록과 이전 이력을 지우려면 모든 기기의 앱 데이터를 먼저 제거한 다음 iCloud 데이터를 삭제해 주세요. 이 순서가 오래된 기기에 남은 데이터의 재업로드를 방지하는 데 필요합니다.

1. 보관할 내용이 있다면 먼저 내보내기

앱 설정의 데이터 관리에서 JSON 파일을 내보낼 수 있습니다. 이 파일에는 해당 기기에 저장된 내용과 이전 변경 이력이 포함됩니다. 다른 기기에만 남은 미동기화 내용은 그 기기에서 별도로 내보내야 합니다. 내보낸 파일은 따로 보관되므로, 아래 삭제 절차로 함께 지워지지 않습니다.

2. 사용했던 모든 기기에서 앱과 로컬 데이터 삭제

iPhone·iPad: 설정 → 일반 → iPhone 저장 공간 또는 iPad 저장 공간 → Daymirror → 앱 삭제를 선택합니다. ‘앱 정리하기’는 데이터를 남기므로 이 절차에 사용하지 마세요. Apple의 앱 데이터 삭제 안내

Mac: Daymirror의 모든 창을 닫는 것에 더해 메뉴에서 Daymirror 종료 또는 ⌘Q로 앱을 종료합니다. Finder의 응용 프로그램에서 Daymirror를 휴지통으로 옮깁니다. 앱 파일 삭제만으로는 저장된 기록이 제거되지 않으므로, 다음 앱 전용 데이터 폴더도 제거합니다.

  1. Finder → 이동 → 폴더로 이동(⇧⌘G)을 엽니다.
  2. ~/Library/Containers/com.planudid.app을 입력합니다.
  3. 해당 경로가 Daymirror의 com.planudid.app 폴더인지 확인한 뒤 그 폴더만 휴지통으로 옮깁니다. 상위 Containers나 Library 폴더를 지우지 마세요.
  4. 휴지통에서 방금 옮긴 Daymirror 앱과 이 데이터 폴더만 선택해 ‘즉시 삭제’를 실행합니다. 다른 파일을 함께 삭제할 필요는 없습니다.

예전에 별도 Daymirror Mac 앱을 설치했다면 그 앱도 종료·제거하고, ~/Library/Containers/com.planudid.mac 폴더가 남아 있는지 같은 방법으로 확인해 제거합니다. 이 두 경로 외에 이름이 비슷한 폴더를 한꺼번에 삭제하지 마세요.

폴더가 없거나 macOS가 접근을 막으면 다른 폴더를 추측해 삭제하지 말고 지원팀에 문의해 주세요. 같은 Mac의 다른 사용자 계정에서도 앱을 사용했다면 그 계정의 데이터도 별도로 정리해야 합니다. Apple의 Mac 앱 제거 안내

현재 꺼져 있거나 오프라인인 기기도 포함합니다. 그 기기를 정리하지 못했다면 오래된 Daymirror를 다시 실행하거나 iCloud에 연결하지 않도록 해 주세요. 다른 기기의 로컬 데이터가 이 절차만으로 원격 삭제되는 것은 아닙니다.

3. 본인의 iCloud에서 Daymirror 데이터 삭제

위 단계를 모든 기기에 적용한 뒤, Daymirror에서 사용했던 Apple 계정으로 로그인한 기기 한 대에서 진행합니다.

  • iPhone·iPad: 설정 → 본인 이름 → iCloud → 저장 공간 또는 계정 저장 공간 관리 → Daymirror를 선택하고 데이터 삭제 항목을 눌러 확인합니다. OS에 따라 버튼 이름이 ‘데이터 삭제’, ‘iCloud에서 삭제’ 등으로 다를 수 있습니다. Apple의 iCloud 저장 공간 안내
  • Mac: 시스템 설정 → 본인 이름 → iCloud → 관리 → Daymirror → iCloud에서 삭제를 선택하고 확인합니다. Apple의 Mac iCloud 데이터 삭제 안내

iCloud 사용 스위치만 끄거나 파일 앱에서 내보낸 JSON만 지우는 것으로는 Daymirror의 iCloud 변경 이력이 삭제되지 않습니다. Daymirror 항목이나 삭제 버튼이 보이지 않으면 사용했던 Apple 계정을 확인한 후 지원팀에 문의해 주세요. 다른 앱이나 기기 전체 백업을 대신 삭제하지 마세요. 여러 Apple 계정에서 Daymirror를 사용했다면 계정마다 iCloud 데이터를 별도로 정리해야 합니다.

4. 백업과 다시 설치하기

iCloud 저장 공간에 삭제가 반영되고 모든 기기의 이전 앱 데이터가 정리된 뒤 다시 설치해 주세요. 삭제 전 기기 백업, Time Machine, Finder 백업 또는 따로 보관한 앱 데이터·JSON 파일에는 이전 내용이 남을 수 있습니다. 이 사본을 복원하면 이전 데이터가 다시 나타날 수 있습니다. 보관 중인 백업·내보내기 사본도 삭제하려면 해당 백업 관리 방법을 별도로 따라 주세요. 앱은 이 사본을 직접 삭제하지 않습니다.

도움이 필요하면: support@hiorio.com으로 사용 기기와 OS 버전, 진행하지 못한 단계를 보내 주세요. Apple 계정 암호나 전체 일정 내보내기 파일은 보내지 마세요. 지원팀은 본인이 기기와 iCloud에서 삭제할 수 있도록 안내합니다.
